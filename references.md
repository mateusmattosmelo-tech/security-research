# References & Reading

The sources I lean on and keep coming back to. Kept short and current on purpose — a map, not a
link dump.

## Standards & taxonomies

- **OWASP Top 10** (web) and **API Security Top 10** — the shared vocabulary for classes and why
  they matter.
- **OWASP ASVS** — a verification checklist that doubles as a testing checklist.
- **OWASP WSTG** (Web Security Testing Guide) — methodical, per-class test procedures.
- **CWE** — the weakness taxonomy triagers map findings to; know the common CWE ids for your bugs.
- **CVSS** spec — how severity is scored; understand each metric before you claim one.

## Practice (legal, intentionally vulnerable)

- **PortSwigger Web Security Academy** — free, excellent, per-class labs (see the `writeups/`
  notes here).
- **DVWA**, **OWASP Juice Shop**, **WebGoat** — self-hosted vulnerable apps.
- **HackTheBox**, **TryHackMe** — broader machines and paths.

## Reference material

- **PortSwigger research** — the source for request smuggling, web cache poisoning, and much of
  the modern web attack surface.
- **PayloadsAllTheThings** — payload/technique reference per class.
- **HackTricks** — broad methodology and cloud/infra notes.
- **The Web Application Hacker's Handbook** — still a solid foundation for method.

## Program & disclosure

- The **policy of whatever program you're on** is the real reference — scope, exclusions, and
  disclosure rules override any general advice here. See
  [scope & disclosure hygiene](methodology/scope-and-disclosure-hygiene.md).
