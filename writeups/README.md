# Write-ups

Finished, sanitized write-ups. Two kinds live here:

- **Practice-lab notes** — walkthroughs of public, intentionally-vulnerable labs (PortSwigger Web
  Security Academy, DVWA, etc.). Legal to publish, and a clean way to show method.
- **Confirmed findings** — sanitized write-ups of real bugs, published only **after** they're
  fixed and disclosure is permitted by the program.
